# Пробная совместимость CozyVoice с голосом ДимаПамперс

Дата: 2026-08-13  
Статус: утверждённая схема, ожидает просмотра документа

## Цель

Проверить, принимает ли Higgsfield модель `cozy_voice` существующий голосовой идентификатор ДимаПамперс, и дать пользователю отдельный OGG-файл для оценки звучания.

## Границы

- Создаётся ровно один тестовый синтез с тем же `voice_id` и `voice_type=element`, что использует работающий бот.
- Тестовая фраза: «Проверка голоса Дима Памперс».
- Новая модель передаётся как `--model cozy_voice`; язык остаётся `ru`.
- Результат скачивается во временное место, локально конвертируется в OGG/Opus и передаётся пользователю для прослушивания.
- `voice.py`, `.env`, база памяти, история, настройки бота и запущенный процесс не меняются.

## Поток

```text
один тестовый запрос Higgsfield
→ результат от cozy_voice или диагностируемая ошибка совместимости
→ при успехе: загрузка MP3 и локальная конвертация в OGG/Opus
→ пользователь слушает файл
→ только отдельное явное решение пользователя может поменять рабочую модель
```

## Ошибки

- Если Higgsfield не поддерживает текущий `voice_id` в CozyVoice, опыт заканчивается без изменения бота.
- При ошибке сети, CLI или конвертации результат не подменяется текущим голосом и не отправляется как успешный.
- В диагностике не выводятся секреты и токены.

## Критерий готовности

Либо существует воспроизводимый тестовый OGG-файл с `cozy_voice`, либо зафиксирована понятная ошибка несовместимости. В обоих случаях рабочий бот продолжает использовать текущий `minimax` до отдельного одобрения смены.
