# Пробная озвучка Qwen Audio 3.0 голосом ДимаПамперс

Дата: 2026-08-13  
Статус: одобрено пользователем

## Цель

Создать один отдельный OGG/Opus-образец через Qwen Audio 3.0 TTS Flash с существующим голосом ДимаПамперс, чтобы пользователь оценил звук до смены рабочего движка.

## Решение

Higgsfield подтверждает совместимость текущего `voice_id` с моделью `qwen_audio`; для пробы используется её отдельный тип задания `qwen_audio_tts`, а не общий `text2speech_v2`. Параметр `format=ogg_opus` создаёт Telegram-совместимый файл напрямую.

Запрос использует текст «Проверка голоса Дима Памперс», `voice_type=element`, текущий идентификатор голоса, частоту 48 kHz и один канал. Никакие production-файлы и процесс бота не изменяются. Успешный файл выдаётся пользователю; смена `voice.py` с `minimax` на Qwen допускается лишь после отдельного согласия.

## Ошибки и границы

- Выполняется ровно один запрос на синтез; ошибка или пустой результат не запускают повторную генерацию без нового согласия.
- Тест не обращается к Telegram, памяти или истории бота.
- Не раскрываются API-ключи, переменные окружения и полные ответы сторонних задач.
- До и после пробы сверяются хэши `voice.py`, `bot.py` и `.env`; работающий процесс не останавливается.

## Критерий готовности

В `artifacts/voice-trials/qwen-audio-dimapampers.ogg` существует непустой файл с Opus, 48 kHz, mono, созданный через `qwen_audio_tts`. Либо пользователю сообщается не секретная ошибка без изменения рабочего голоса.
